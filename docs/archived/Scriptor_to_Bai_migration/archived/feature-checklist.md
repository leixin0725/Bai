## 0. 说明与填写约定

### 比较对象

- **Bai**：`Bai/`，当前正在从头开发的独立服务端（命令行交互、单用户、全天运行）。
- **qqbot**：`qqbot/`，AstrBot + NapCat(OneBot) 部署的学习副本。框架能力以 AstrBot 官方文档为准，插件能力以仓库内插件源码为准。

### Bai 已有能力（对照，不计入缺失清单）

以下能力 Bai 已具备或已预留，清单中不再重复列出：

- 永久保存完整对话记录，长期记忆有来源可追溯；
- 独立配置的多套人格（聊天、记忆整理、状态），以及提示词模板和内容边界管理；
- 在近期对话窗口边界自动整理长期记忆，保留原始来源；
- 模型可查询记忆（只读），写操作的事务安全协议已预留但尚无实际写功能；
- 自主行动循环框架已预留但默认关闭；
- 本地逐请求审批的提示词调试工具、用量估算、请求重试；
- 凭据保护、数据文件权限收紧、泄露事件告警与处置流程；
- 命令行管理功能（配置校验、聊天、记忆维护、健康检查、安全事件查看）。

- [x] 后台异步任务机制：任务排队、执行、状态查看
- [x] 并发控制：同一会话不重复处理、限制并行请求、重要请求优先
- [x] 生命周期管理：正常启动/停止、清理资源、优雅退出
- [x] 运行状态与统计信息查看（当前会话、队列、任务、健康度）

## 2. 模型接入与生成

> 已移入档案：图像理解（未来考虑）；语音输入、语音输出、文生图（可舍弃）

- [ ] 支持接入多家模型服务，可在不同模型间切换，失败时自动回退
- [x] 流式输出（边生成边显示）
- [!] 超长对话自动压缩：超出模型容量时压缩/概括而不是简单丢弃
- [x] 关键判断使用轻量模型：如判断是否需要检索记忆、是否值得回复，降低延迟和成本
- [x] 定时任务到期时由模型自主理解并执行，而不是机械回复（见第 10 节）

## 3. 对话与自主行动编排

> 已移入档案：多会话管理（可舍弃）、多种代理运行后端（明确不做：只跑在本地，不考虑第三方）

- [x] 子代理/多代理协作：把任务分给多个专门人格处理，并可在它们之间交接（**长期需求核心**）
- [!] 多套人格的组合与切换：不同场景使用不同人格或组合
- [x] 完整工具调用循环：一次回复中可并行调用多个工具、多轮续接、可取消
- [!] 主动行动：不是只能被动回复，而是能按计划、按状态主动发起动作（含主动回复/开口时机判定，与心跳机制合并考虑，细节实现阶段再定）
- [x] 自定义触发规则：按消息内容、时间、事件等条件触发预设行为

## 4. 工具与执行能力

> 已移入档案：代码/命令执行能力、外部服务协议接入（未来考虑）；远程编码代理接入（并入未来插件系统，本次不做）

- [x] 文件操作：读、写、编辑、搜索、列表、删除、发送文件
> 对标astrbot内置工具
- [x] 网页抓取与联网搜索：获取指定网页内容，多来源搜索
- [!] 修改数据类操作的安全保障：按工具分级授权、敏感操作需确认、全程留痕、失败不留半截副作用
- [x] 工具可用性监控：某个工具反复失败时自动停用或降级，并告知模型
- [x] 工具自动发现与推荐：模型能自己找到合适的工具，而非只能使用预设清单
- [ ] 危险操作确认流程：删除、重置等操作需用户二次确认，确认有超时
- [ ] 浏览器操作能力：打开页面、点击、填写（**未来考虑**）
- [x] 文件变更监控：被关注的文件变化时触发通知

## 5. 消息与交互体验

> 已移入档案：消息格式净化、引用/回复指定消息、图片/文件附件收发、打字/发送节奏模拟（未来考虑）
> 主动回复判定已并入「主动行动」与「心跳机制」，不再单列（细节实现阶段再定）

- [!] 短时间连续消息合并：智能判断用户的"一次对话动作",多句话合并为一条处理，避免重复回复
- [!] 长回复自动分段：超长内容按语义分段发出，分段间模拟自然停顿

## 6. 记忆系统

- [ ] 分范围记忆：个人记忆与全局记忆分离（群范围记忆**可舍弃**）
- [x] 多种记忆类型与组织：偏好、事实、事件、经验/技能等分类，可设优先级与有效期
- [x] 日记：按日期记录当天发生的事情，可回看和搜索
- [!] 记忆检索：同时支持关键词和语义两种方式，结果按相关度排序，可覆盖记忆文件之外的内容
- [!] 记忆关联图谱：自动发现人与人、事、物之间的关系，按主题回忆
- [!] 自动提取值得记住的信息：由子agent从对话中提炼事实、偏好、经验，而不是全靠手动记
- [!] 定期整合巩固：空闲时把近期记忆整理进长期记忆，生成每日摘要
- [!] 定期自我反思：按消息量/时间/主题触发，回顾并改进自己的行为
- [!] 检索结果链式组织：一次检索后可顺着相关记忆继续追问
- [x] 记忆冲突发现与处理：新记忆与旧记忆矛盾时提示并解决
- [ ] 敏感记忆加密存储
- [x] 记忆归档：过时记忆自动归档，保持活跃记忆精简
- [x] 记忆健康查看：查看记忆状态、覆盖范围、维护建议
- [x] 上下文索引：模型可查看自己有哪些文件/资料可用，再按需读取
- [x] 对话记录账本：结构化记录会话供统计回溯（Bai 已有原始记录，此项为可选补充）

## 7. 身份、权限与安全

> 已移入档案：跨平台身份统一（未来考虑）

- [x] 用户画像与称呼：记住用户的偏好、称呼、常用别名
- [ ] 权限分级：区分管理员与普通用户，不同级别可用功能不同（群成员维度**可舍弃**）
- [x] 临时提权会话：敏感操作需临时提权，提权有时效并全程记录
- [x] 自动审批模式：提权请求可以由其它agent/人格代处理
- [x] 操作审计：谁、何时、执行了什么敏感操作，可回溯
- [x] 重要操作二次确认：删除、解绑、重置等危险操作需多次确认
- [ ] 路径与网址安全校验：防止越权读取本地文件或访问恶意地址
- [ ] 自动备份与恢复：定期备份数据，可手动触发和恢复

## 8. 知识库与学习

- [x] 知识库管理：增、删、改、查、分类、统计
- [x] 知识库语义检索：按意思找知识，而不只是关键词
- [x] 学习模式：开启后自动从对话中积累知识，不打断对话(智能开启或者用子agent)
- [x] 待确认知识：自动提取的知识先进入待确认队列，经用户确认后入库
- [ ] 授课模式：主动向用户讲解知识，可设置严格程度
- [x] 专题研究：针对一个主题多轮搜索、整理、产出研究报告
- [x] 文档学习：导入文档后自动提取并纳入知识库
- [x] 知识冲突检测：新知识与已有知识矛盾时提示
- [x] 自身使用说明检索：模型遇到不会的功能时，可查询自己的功能说明

## 9. 档案、文件与媒体(暂时不做)

- [ ] 档案管理：上传、重命名、移动、复制、删除
- [ ] 媒体自动保存：收到的图片/文件自动归档并去重
- [ ] 媒体库检索与发送：按关键词/时间找回之前的图片或文件
- [ ] 图片相似查找：根据一张图片找到相似图片（群范围**可舍弃**）
- [ ] 媒体保留策略：设置保存时长、大小限制、类型白名单

- [x] 任务链：模型执行任务时可以给自己追加后续任务，实现接力式自主行动

- [x] 夜间维护：闲时自动整理、备份、清理
- [ ] 每日摘要：每天生成当日对话/活动摘要
